# DeepSeek V4 Flash 0731 on DGX Spark

Planned two-node TP=2 vLLM runtime for `deepseek-ai/DeepSeek-V4-Flash-0731` on
two NVIDIA DGX Sparks.

The definition remains disabled while the 0731-native vLLM baseline and the
required SM121 FlashInfer, b12x, NVFP4 DS-MLA, and DSpark changes are audited.
No image can be built from this directory yet.
